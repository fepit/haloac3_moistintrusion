Code to reproduce the moist intrusion analysis from the Halo-AC3 campaign in Pithan et al. 2026
hac3_paper.ipynb contains the code to plot observational and reanalysis data (data paths at top of notebook to be adjusted)
prw_plot.ipynb contains the code to plot ICON data from DYAMOND3 using the intake library from the WCRP km-scale Hackathon in 2025
requirements.txt provide the python packages needed to execute the code
